## 🎯 Goal

The main goal of this repository is to understand:

- How software systems are designed
- How different components communicate
- How large-scale applications work
- How systems handle millions of users
- How applications are made scalable and reliable
- How databases, caches, APIs, servers, and other components work together
- How to approach System Design interview questions

## 📝 How I Study

For every topic, I maintain **two types of notes**.

### 1. 📖 Detailed Notes

Each topic contains a detailed `README.md` with:

- Concept explanation
- Important definitions
- Examples
- Diagrams
- Real-world use cases
- Advantages and disadvantages
- Interview points

These notes are mainly for **understanding the concept deeply**.

### 2. ✍️ Personal Written Notes

I also maintain my own handwritten notes for every topic.

These are mainly for:

- Quick revision
- Remembering important points
- Simplifying difficult concepts
- Last-minute interview preparation

### Study Flow

**Learn → Understand → Write Detailed Notes → Make Personal Notes → Revise → Apply**
